📱 Suica / Pasmo ใน Apple Wallet
Wallet → (+) → Transit Card → ค้นหา "Suica" หรือ "Pasmo" → เติมเงินผ่าน Apple Pay (รองรับ Visa / Mastercard / Amex บางประเภท) → แตะโทรศัพท์ที่ทางเข้าได้เลย
🟢 ซื้อบัตร Suica (ตู้สีเขียว JR East) — แนะนำ
พิกัด: ออก Arrival Hall → เดินตามป้าย Tokyo Monorail → ผ่าน Information Center → เลี้ยวซ้าย → เจอ Seven Bank ATM / ตู้จอง JR East / ตู้ Suica เรียงกัน → ตู้ไกลสุด = ตู้สีเขียว
ใช้เงินสด · เติม 1,000–10,000¥ · ใช้ได้ 28 วัน · เงินเหลือคืนไม่ได้ · ซื้อสำรองที่ Ninja Wifi ชั้น 2 Terminal 3 ใกล้จุดจอดรถบัส เปิดถึง 23:45

⚠️ เลือก 2 แบบ:
✅ Name-Inscribed Suica (แนะนำ) — พิมพ์ชื่อลงหน้าบัตร ถ้าหายออกใบใหม่ทดแทนได้
⬜ Blank Suica — ไม่ระบุชื่อ ถ้าหายหายเลย ออกใหม่ไม่ได้

ขั้นตอน (Name-Inscribed): กด English (ที่มุมขวาบน) → เลือก "Name-Inscribed Suica" → กด Agree (ยอมรับเงื่อนไข) → กรอก ชื่อ-นามสกุล (ตาม Passport) / เพศ+วันเกิด (ปี ค.ศ.-เดือน-วัน) / เบอร์โทร (ใส่เบอร์ไทยได้) → เลือกจำนวนเงิน (เช่น 1,000 / 2,000 / 5,000 / 10,000¥ — มีหักมัดจำ 500¥) → จ่ายเงิน: สอดธนบัตรหรือหยอดเหรียญลงในช่องเรืองแสง → รับบัตรช่องซ้ายมือ
Welcome Suica ไม่มีค่ามัดจำ 500¥ เงินที่จ่ายไปจะเป็นเงินในบัตรทั้งหมด แต่ออกใหม่ไม่ได้ถ้าหาย

ทาง 1 — Hibiya Line → Ningyocho → Haneda ⭐
⭐ แนะนำ · Suica · ออกไม่เกิน 21:00 · ~35–50 นาที
ดูขั้นตอนเดินทาง
1เดินออกจากโรงแรมเลี้ยวขวา → เดินไปเรื่อยๆ → เจอสี่แยก Showa-dori → หาป้ายสถานี Iriya (Hibiya Line สีเทา)
ลิฟต์อยู่ฝั่งตรงข้าม ข้ามทางม้าลาย 2 จุด → หาป้าย "Elevator to Platform 1" ไปทาง Ueno/Ginza
2แตะบัตรเข้า → ขึ้นขบวนไหนก็ได้ที่ไปทาง Ueno/Ginza/Naka-meguro → ลง Ningyocho (H14)
3มองป้าย A สีชมพู หรือ Toei Asakusa Line → หาสัญลักษณ์ลิฟต์เพื่อข้ามไปสายสีชมพู → แตะบัตรเข้า → ชานชาลา 1 เขียนว่า Nihombashi/Sengakuji/Haneda Airport
4รอขบวน ไป Haneda Airport เท่านั้น:
🟢 Airport Kaitoku (เขียว) = เร็วสุด · 🟠 Access Express (ส้ม) = เร็ว · ⬛ Local/ขาวดำ = ได้แต่ช้า
🚫 ห้ามขึ้นขบวนที่เขียนไป Nishi-magome
5ลง Haneda Airport Terminal 3 → ลากกระเป๋าตามสัญลักษณ์เครื่องบิน+ลิฟต์ → กดชั้น 1 (ออกสถานี แตะบัตรออก) → ลิฟต์ขึ้น ชั้น 3 จุดเช็คอิน NH877
