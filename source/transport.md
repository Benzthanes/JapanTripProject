## เส้นทางที่ 0 — Haneda Airport → Asakusabashi | 10 ธ.ค.

> ผ่าน ตม. ได้ก่อน 23:30 น. มี 3 เส้นทาง

---

### 🔴 ทาง 1 — Keikyu Airport Line (แนะนำสุด) ~610¥

ออกจาก Terminal 3 ชั้น 2 (ขาเข้าประเทศ) → เดินออกมาจะเห็น Information counter → ไปทางขวามือ → เจอป้ายสีแดงเขียนว่า Keikyu Line → เดินตามป้าย → เจอสถานี **Haneda Airport Terminal 3**

**ซื้อตั๋ว / บัตร (เลือกอย่างใดอย่างหนึ่ง)**

- **ตู้อัตโนมัติ** — เลือก TH/EN → เลือกปลายทาง Asakusabashi → จ่ายเงินสด/บัตร ~610¥
- **Suica/Pasmo ใน Apple Wallet** — Wallet → (+) → Transit Card → ค้นหา "Suica" หรือ "Pasmo" → เติมเงินผ่าน Apple Pay (รองรับ Visa/Mastercard/Amex บางประเภท) → แตะโทรศัพท์ที่ทางเข้าได้เลย
- **ซื้อบัตร Suica (ตู้สีเขียว JR East)** — ออกจาก Arrival Hall → เดินตามป้าย Tokyo Monorail → ผ่าน Information Center → **เลี้ยวซ้าย** → เจอ Seven Bank ATM / ตู้จอง JR East / ตู้ Welcome Suica เรียงกัน → เดินไปที่ **ตู้ไกลสุด** = ตู้ Suica สีเขียว · ใช้เงินสด · เติม 1,000–10,000¥ · ใช้ได้ 28 วัน · **เงินเหลือคืนไม่ได้**
  - ซื้อสำรองได้ที่ **Ninja Wifi** ชั้น 2 Terminal 3 ใกล้จุดจอดรถบัส เปิดถึง **23:45**
  - **2 แบบให้เลือก:**
    - **Name-Inscribed Suica** (แนะนำ) — พิมพ์ชื่อลงหน้าบัตร **ถ้าหายออกใบใหม่ทดแทนได้**
    - **Blank Suica** — ไม่ระบุชื่อ **ถ้าหายหายเลย ออกใหม่ไม่ได้**
  - ขั้นตอนซื้อ (Name-Inscribed): กด English → เลือก "Name-Inscribed Suica" → กด Agree → กรอก ชื่อ-นามสกุล (ตาม Passport) / เพศ+วันเกิด / เบอร์โทร (ใส่เบอร์ไทยได้) → เลือกจำนวนเงิน (มีหักค่ามัดจำ 500¥) → จ่ายเงิน → รับบัตรช่องซ้ายมือ
  - Welcome Suica **ไม่มีค่ามัดจำ 500¥** แต่ออกใหม่ไม่ได้ถ้าหาย

**ขึ้นรถไฟ**

1. มองป้ายสีแดง **"Keikyu Line"** → แตะบัตรเข้าเกทที่แถบสีฟ้า (สัญลักษณ์ IC)
2. ลงชานชาลา:
   - บันไดเลื่อน: ตามป้าย "Shinagawa / Asakusa / Yokohama" ส่วนใหญ่ชานชาลา 2
   - ลิฟต์: สัญลักษณ์สีฟ้า → ชั้น 1 → ออกลิฟต์ไปทาง Track 2

**เลือกขบวนที่ถูก — สำคัญมาก**

- มองป้ายไฟเขียนว่า **"Through Asakusa Line"** หรือจุดหมาย **Asakusa / Narita Airport / Inba-nihon-idai / Aoto / Oshiage** → ไม่ต้องเปลี่ยนสาย นั่งถึง **Asakusabashi (A16)** เลย
- **ห้ามขึ้นขบวน Yokohama**
- หากรถสุดที่ Sengakuji / Shinagawa → ลงรอที่ชานชาลาเดิม รอขบวนถัดไปที่ไปทาง Asakusa

**ถึง Asakusabashi (A16)**

- มองป้ายสีเหลือง **"Exit A3"** บนเพดาน/เสา → แตะบัตร Suica ออก → เดินออก Exit A3
- ถ้าหาป้าย A3 ไม่เจอ ให้หา "Edo-dori Avenue" หรือ "JR Asakusabashi Station" ทางออกอยู่ฝั่งเดียวกัน
- ขึ้นมาบนถนน → **เลี้ยวขวา → เดิน 150 เมตร → เจอโรงแรม**

### ⬛ ทาง 2 — Monorail → Daimon (ใต้ดิน) → Asakusabashi

> ⚠️ ต้องถึงสนามบินก่อน 23:45 (Daimon ออก 00:05)

1. เข้า Monorail แตะบัตร → ลิฟต์ขึ้นชั้น 3 (Platform 2) หรือบันไดเลื่อนหาป้าย **Platform 2 - For Hamamatsucho**
2. ขึ้นรถ **For Hamamatsucho**:
   - สีแดง — Haneda Express (Last 23:48)
   - สีน้ำเงิน — Rapid (Last 00:10)
   - สีเขียว — Local (Last 00:10)
3. ลง **Hamamatsucho** → มองป้ายเหลือง **North Exit** → แตะบัตรออก → ลงลิฟต์/บันไดเลื่อนชั้น 1
   - ทริก: เดินไปหัวขบวน สังเกตป้ายเหลือง North Exit
4. ออกจากสถานีเดินตรง → เจอสี่แยก Starbucks ตรงหัวมุม → เจอป้ายลงใต้ดิน **Daimon (A09)** → เลือก Exit B4 (มีลิฟต์ลงไป)
5. เข้าสถานี แตะบัตร → เดินตามป้ายสีชมพู **(สาย A)** เขียนว่าไป Asakusa/Oshiage
6. ชานชาลา 2 → นั่งไปลง **Asakusabashi (A16)** → ออก Exit 3 → เลี้ยวขวา → โรงแรม

### 🚂 ทาง 3 — Monorail → JR Akihabara → JR Asakusabashi ~650¥

1. เข้า Monorail แตะบัตร → ลิฟต์ขึ้นชั้น 3 (Platform 2) หรือบันไดเลื่อนหาป้าย **Platform 2 - For Hamamatsucho**

## เส้นทางที่ 1 — Tokyo → Fujinomiya | 12 ธ.ค.

> 💡 มีรถรับส่งโรงแรมถึง Akihabara เช้าจนถึง 10 โมง

---

### 🚌 ทาง 1 — บัส (แนะนำ) ~2,000–3,300¥ / 2:30 ชม.

จอง: **[shizuokabus.co.jp](https://www.shizuokabus.co.jp/foreigner/en/express/fujifujinomiya.html#fare)** — จองล่วงหน้า 1 เดือน | รอบแรก ~08:10 | ลงสถานี **Fujinomiya Sta.**

**จากโรงแรม Toyoko Inn Asakusabashi ไป Tokyo Station**

1. ออกจากโรงแรมเลี้ยวซ้าย ถนน Edo-dori → เจอสี่แยกใหญ่ (มีรางรถไฟยกระดับด้านบน) → ถึงใต้ทางด่วนเลี้ยวขวา → เข้า **JR Asakusabashi (East Exit / Hagashiguchi)**
2. แตะบัตร → หา **Platform 1 (Chou Sobu Line สีเหลือง)** → ไป Akihabara/Shinjuku/Mitaka (ไม่ใช่สาย Asakusa Line สีชมพูใต้ดิน) → นั่ง 1 สถานี → ลง **Akihabara**
3. มองป้ายสีเขียว (Yamanote) หรือสีฟ้า (Keihin-Tohoku) → ชานชาลา 4 → ขึ้นขบวนไป **Tokyo/Ueno** → นั่ง 2 สถานี (ผ่าน Kanda) → ลง **Tokyo Sta.**
4. มองป้าย **Yaesu South Exit** → เดินตามลูกศรออกประตูกระจกใหญ่ → เจออาคารสถานีบัส
5. หาตู้ขายตั๋วอัตโนมัติ (ถ้ายังไม่ซื้อ) → เช็คหน้าจอประกาศว่ารถเทียบช่องไหน (ปกติ 8, 9) → ขึ้นรถ **Fujikyu** ป้ายข้างรถเขียนว่า Fujikyu (ถ้าไม่มีป้าย ถามคนตรวจตั๋วก่อนขึ้น)

### 🚂 ทาง 2 — รถไฟ (สำรอง) จ่ายผ่าน Suica

1. เส้นทาง Asakusabashi → Akihabara → Tokyo Sta. เหมือนทาง 1 ข้อ 1–3
2. ที่ Tokyo Sta. ชั้น 2 → มองป้ายสีส้ม **Tokaido Line** (เลข 7–10) → หาชานชาลา 9–10
3. ขึ้นขบวนไป **Atami / Numazu** หรือ **Shizuoka / Shimada** (ดูป้ายข้างตัวรถ + ตารางที่ชานชาลา):
   - **Shizuoka/Shimada** → ลง **Fuji Sta.** ได้เลย
   - **Atami** → ลงแล้วเปลี่ยน Tokaido Line ไป Shizuoka/Shimada (ชานชาลาตรงข้าม) ขบวนเป็น **JR Central สีส้มขาว**
   - **Numazu** → ลงแล้วเปลี่ยนชานชาลาถัดไปไป Shizuoka/Shimada
4. ถึง **Fuji Sta.** → มองป้ายสีแดง **Minobu Line** หรือป้ายชานชาลา Fujinomiya/Kofu → ขึ้นบันไดเลื่อนข้ามไปชานชาลา 1–2 (ตู้ขาว-ส้ม รถมีทุก 20–30 นาที) → ลง **Fujinomiya Sta.**

## เส้นทางที่ 4 — Kawaguchiko → Oku-Asakusa | 18 ธ.ค.

**บัส Kawaguchiko → Busta Shinjuku → TX Line → Oku-Asakusa** ~2+ ชม.

จอง: **[highwaybus.com](https://www.highwaybus.com/gp/inbound/inbPlanList?mode=search#direction)** | ลงสถานี **Busta Shinjuku (Shinjuku Express Bus Terminal)**

**จากโรงแรม Habitacion ไปสถานีบัส**

1. ออกจากรั้วโรงแรมเลี้ยวขวาไปถนนใหญ่ → ฝั่งตรงข้ามมี 7-Eleven → เดินทิศตะวันออก → เลี้ยวขวาที่สี่แยกที่มีร้านขายของฝาก → เดินต่อจะเห็น **อาคารไม้ทรงยุโรป** = สถานี Kawaguchiko
2. ที่สถานี ไม่ต้องเข้าไปในรถไฟ → หาลานจอดบัส → เสาป้าย **หมายเลข 3 หรือ 4** (เช็คหน้าจอ LCD ชานชาลา) → ขึ้นรถดูป้าย **Shinjuku**

**จาก Busta Shinjuku ไป Oku-Asakusa**

1. รถจอดชั้น 3 → ลงรับกระเป๋า → ลิฟต์/บันไดเลื่อนลงชั้น 2 → เชื่อมต่ออาคาร **JR Shinjuku (Exit New South Gate)**
2. มองป้ายเหลือง **Chou Sobu Line** ชานชาลา 13, 16 → ขึ้นขบวนไปทาง Akihabara/Chiba → ลง **Akihabara**
3. มองป้าย **Central Gate** → ออกช่องตรวจตั๋ว JR **เลี้ยวขวาทันที** → เดินออกนอกอาคาร → เห็น Yodobashi Camera → ทางเข้า TX อยู่ลานหน้าตึก
4. หาลิฟต์สัญลักษณ์ **TX สีน้ำเงิน-แดง** → ลงชั้น 1 → สถานี **TX Akihabara** → แตะบัตรเข้า
5. ลิฟต์ไป Platform 1, 2 (ชั้น B4) → รอรถไปทาง **Asakusa/Tsukuba** → นั่ง 2 สถานี → ลง **Asakusa (TX03)**
6. ออก **Exit A1** → ลิฟต์ขึ้นมา → เลี้ยวขวา → เดิน 850 เมตร (ผ่าน Donki ขวามือ → ข้ามสี่แยก) → **Hotel Little Bird Oku-Asakusa** อยู่ในซอยขวามือ

### 🚇 ทาง 1 — Hibiya Line → Toei Asakusa Line → Haneda (แนะนำ)

1. เดินออกจากโรงแรมเลี้ยวขวา → เดินไปเรื่อยๆ → เจอสี่แยก Showa-dori → หาป้ายสถานี **Iriya (สาย Hibiya Line สีเทา)**

2. แตะบัตรเข้า → ขึ้นขบวนไปทาง **Ueno/Ginza/Naka-meguro** → ลง **Ningyocho (H14)**
3. มองป้าย **A สีชมพู** หรือ **Toei Asakusa Line** → หาสัญลักษณ์ลิฟต์เพื่อข้ามไปสายสีชมพู → แตะบัตรเข้า → ชานชาลา 1 เขียนว่า Nihombashi/Sengakuji/Haneda Airport

   - 🟢 **Airport Kaitoku** (แถบสีเขียว) = เร็วสุด
   - 🟠 **Access Express** (สีส้ม) = เร็ว
   - ⬛ Local/ขาวดำ = ได้แต่ช้า
